🔌 API Endpoints

Custom Recorder API

POST /api/recording/start - Start new session
POST /api/recording/event - Record event
POST /api/recording/end/{sessionId} - End session
GET /api/recording/sessions - Get all sessions
GET /api/recording/events/{sessionId} - Get session events

RRWeb Replay API

POST /api/replay/ingest - Ingest RRWeb events
GET /api/replay/sessions - Get all replay sessions
GET /api/replay/events/{sessionId} - Get replay event batches
GET /api/replay/session/{sessionId} - Get session details
