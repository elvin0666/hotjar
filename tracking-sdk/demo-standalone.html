Standalone Hotjar Demo

Self-starting tracking with no configuration needed

Usage Examples

Example 1: Auto-start with default config

<script src="http://localhost:8080/hotjar.js"></script>

This will auto-start tracking with default configuration.

Example 2: Auto-start with custom config

<script> window.HJ_CONFIG = { projectId: "my-project-123", endpoint: "http://localhost:3001/v1/ingest", debug: true }; </script> <script src="http://localhost:8080/hotjar.js"></script>

Define HJ_CONFIG before loading the script for custom configuration.

Example 3: Manual start

<script> window.HJ_AUTO_START = false; </script> <script src="http://localhost:8080/hotjar.js"></script> <script> // Start manually later HJ.start(); </script>

Disable auto-start and manually initialize when ready.

Example 4: Using Public API

// Track custom events HJ.track('purchase', { amount: 99.99, currency: 'USD' }); // Identify user HJ.identify('user-123', { name: 'John Doe', plan: 'pro' }); // Update config HJ.config({ debug: true }); // Manage consent HJ.consent(false); // Revoke consent // Stop tracking HJ.stop();
